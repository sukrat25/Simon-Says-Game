# 🎮 Simon Says Game

An interactive browser-based memory game inspired by the classic Simon Says game. Built using HTML, CSS, and JavaScript, it challenges players to remember and repeat an increasingly complex sequence of colors.

🔗 **GitHub Repository:** [Simon-Says-Game](https://github.com/sukrat25/Simon-Says-Game)

## ✨ Features

- **Interactive Gameplay:** Repeat the color sequence generated by the game in the correct order.
- **Randomized Sequences:** Experience a new sequence as the game progresses.
- **Progressive Difficulty:** Each successful round increases the sequence length.
- **Visual Feedback:** Color flashes and button animations indicate the game sequence and player interactions.
- **Level Tracking:** Track your progress as you advance through the game.
- **Game Over Detection:** The game ends when an incorrect color is selected.
- **Replay Functionality:** Restart the game and challenge yourself to beat your previous score.

## 🛠️ Tech Stack

- **HTML5** — Structures the game interface.
- **CSS3** — Styles the game board and creates visual effects and animations.
- **JavaScript** — Implements game logic, sequence generation, event handling, and input validation.

## 🎮 How to Play

1. Open the game in your browser.
2. Press a key to start the game, if required by the implementation.
3. Observe the sequence of flashing colors.
4. Click the corresponding buttons in the same order.
5. Complete each sequence correctly to advance to the next level.
6. Avoid incorrect selections, or the game will end.
7. Restart and try to achieve a higher level.

## 🚀 Getting Started

### Run Locally

Clone the repository:

```bash
git clone https://github.com/sukrat25/Simon-Says-Game.git
```

Navigate to the project directory:

```bash
cd Simon-Says-Game
```

Open the main HTML file in your browser. If your entry file is named `index.html`, open that file; otherwise, use the HTML filename included in the repository.

No backend or database setup is required.
